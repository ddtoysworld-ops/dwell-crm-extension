# D'WELL CRM 插件 0.8.71

供 D'WELL 员工试用的 Chrome 插件安装包。连接正式业务系统；下载插件不代表获得后台账号权限。不要在同一个聊天页面同时启用新旧两份 CRM 插件。

## 下载与更新

1. [下载 0.8.71 安装包](https://github.com/ddtoysworld-ops/dwell-crm-extension/raw/refs/heads/main/D-WELL-CRM-v0.8.71.zip)，解压到固定目录。
2. 在 Chrome 的 `chrome://extensions` 开启开发者模式，选择「加载已解压的扩展程序」，选取包含 `manifest.json` 的目录。
3. 确认显示版本 `0.8.71`，停用旧版插件，再使用获授权的员工账号登录。
4. 已安装插件不会从 GitHub 自动更新。若是更新原有安装，请替换原加载目录中的文件，在 `chrome://extensions` 点「重新载入」，再刷新 WhatsApp 或 Messenger 页面。

安装包 SHA-256：`6359B9D5869E7113B96F54D09DE3393027C3EFBE243437C655F9D09BF01B2A29`。

## 0.8.71 试用范围

- 保留 CRM 进单、客户查询、地址复制、优惠券与奖品、好友推荐、幸运抽奖、Flow 和配套资料。
- AI 回复支持选择 Agent、抓取近期已加载的双方文字及语音、生成可编辑草稿、推荐 0–5 张照片，并查看顾客情况与简短对话进度。照片和回复均由客服核对后自行发送，插件不会自动发送。
- 本轮回复优先处理最新、连续的顾客问题；先前已发出的客服消息作为背景，避免重复作答。Messenger 自动 Flow 按钮文字不能当作顾客亲口症状。
- 「保存更好回答」及后台自动提炼优秀回复仍未开发，不包含在此版本。
- 请先用获授权的测试对话试用 AI 回复及语音；真实顾客消息、价格、健康资料和推荐照片都须人工核对。遇到无法识别的消息方向，不要把草稿直接发送。

## 旧版记录

## 0.8.57 本次修正

- WhatsApp 更改了个人对话页的联系人资料标记。新版能识别目前的英文、简体及繁体标记，避免旧版一直显示「暂不能确认这是个人对话」；群组和不明确页面仍不会当作个人顾客。
- 保留 0.8.43 及更早版本的独立压缩包，不覆盖旧包。需要退回旧版时可下载相应版本，但旧版可能无法识别新版 WhatsApp 页面。
- 现有配套资料仍可查看并复制。AI 回复功能仍在完善与验证中，不应当作正式自动回复流程；插件不会自动发送顾客消息。

## 0.8.43 相比 0.8.42

- AI 回复助手的「顾客问题 / 草稿」支持手动口述。客服先选中文、English 或 Bahasa Melayu；识别文字进入可编辑草稿，不会自动生成或发送消息。
- Chrome 可能通过在线语音服务处理音频；使用前须允许麦克风，发送前核对姓名、电话、金额和产品名。浏览器不支持时仍可打字。
- 订单、优惠券、推荐、抽奖、Flow 和数据库规则没有变化。

## 0.8.42 已有功能（相比 0.8.24）

- WhatsApp 有完整号码时按号码识别；仅显示 `@用户名` 或姓名时，按唯一精确匹配显示客户资料。重名或不明确时不自动选客户，也不凭姓名永久绑定聊天。切换对话会清除旧客户上下文。
- 客户档案显示动态购买标签；当前收货资料与旧地址分别展示。旧地址可供一键复制，但不会自动填入新订单；多地址时须先选择。
- 上门购买作为交付方式，不要求邮寄地址、ERP ID、运单号或运费。寄送订单保留原有校验，东马运费建议仍可人工调整。
- 优惠券与待寄奖品合并显示数量；有权限的员工可在插件登记留到下次或已寄出，寄出时填写运单号。
- AI 配套资料可分别复制原配套话术和表格 E 列补充话术；E 列为空时不显示可用的复制动作。
- 原有 Flow 发送代码保持不变；发送仍由员工操作，不会因为客户匹配而自动发送。
