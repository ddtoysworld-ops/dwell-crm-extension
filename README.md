# D'WELL CRM 插件 0.8.16

此仓库仅供已获授权的 D'WELL 员工下载正式版 Chrome 插件。安装包连接正式 Supabase 项目，可保存订单及操作客户资料；不要与旧版客服插件同时在同一聊天页面启用。

## 安装

1. 下载 `D-WELL-CRM-v0.8.16.zip`，解压到不会随意移动的文件夹。
2. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择解压后包含 `manifest.json` 的文件夹。确认扩展版本显示 `0.8.16`。
4. 停用旧版 D'WELL 客服插件，然后用管理员分配的账号登录新版插件。

## 更新

GitHub 下载的已解压插件不会自动更新。收到新版本通知后，下载对应版本安装包，替换已加载文件夹内的插件文件，再到 `chrome://extensions` 点击重新加载；不要把新旧版本同时用于同一个对话。
