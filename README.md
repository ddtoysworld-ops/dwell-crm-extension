# D'WELL CRM 插件 0.8.17

此仓库公开提供正式版 Chrome 插件安装包；下载不代表取得系统使用权限，只有获授权的 D'WELL 员工才能登录。安装包连接正式 Supabase 项目，可保存订单及操作客户资料；不要与旧版客服插件同时在同一聊天页面启用。

## 安装

1. 到 [最新版本](https://github.com/ddtoysworld-ops/dwell-crm-extension/releases/latest) 下载 `D-WELL-CRM-v0.8.17.zip`，解压到不会随意移动的文件夹。
2. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择解压后包含 `manifest.json` 的文件夹。确认扩展版本显示 `0.8.17`。
4. 停用旧版 D'WELL 客服插件，然后用管理员分配的账号登录新版插件。

## 本次更新

查询客户时显示全部已保存的收货资料和不重复的历史地址。默认地址会先选中；没有默认地址而有多条地址时，须先选定一条。「一键复制客户资料」会复制所选地址对应的收件人、电话和地址。

## 更新

GitHub 下载的已解压插件不会自动更新。收到新版本通知后，下载对应版本安装包，替换已加载文件夹内的插件文件，再到 `chrome://extensions` 点击重新加载；不要把新旧版本同时用于同一个对话。
