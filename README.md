# D'WELL CRM 插件 0.8.18

此仓库公开提供正式版 Chrome 插件安装包；下载不代表取得系统使用权限，只有获授权的 D'WELL 员工才能登录。安装包连接正式 Supabase 项目，可保存订单及操作客户资料；不要与旧版客服插件同时在同一聊天页面启用。

## 安装

1. 到 [最新版本](https://github.com/ddtoysworld-ops/dwell-crm-extension/releases/latest) 下载 `D-WELL-CRM-v0.8.18.zip`，解压到不会随意移动的文件夹。
2. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择解压后包含 `manifest.json` 的文件夹。确认扩展版本显示 `0.8.18`。
4. 停用旧版 D'WELL 客服插件，然后用管理员分配的账号登录新版插件。

## 本次更新

WhatsApp Flow 刷新会重新识别当前顾客对话，发送前再次核对；兼容旧版 WhatsApp 聊天标题结构。群聊、切换对话和已有草稿仍禁止发送。插件也减少未切换顾客时的重复查询和断线时的高频轮询。后台网站的性能修复尚未发布。

0.8.17 已加入多地址显示与一键复制所选地址，此功能保留。

## 更新

GitHub 下载的已解压插件不会自动更新。收到新版本通知后，下载对应版本安装包，替换已加载文件夹内的插件文件，再到 `chrome://extensions` 点击重新加载；不要把新旧版本同时用于同一个对话。
