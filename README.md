# D'WELL CRM 插件 0.8.79

供 D'WELL 员工试用的 Chrome 插件安装包。连接正式业务系统；下载插件不代表获得后台账号权限。不要在同一个聊天页面同时启用新旧两份 CRM 插件。

## 下载与更新

1. [下载 0.8.79 安装包](https://github.com/ddtoysworld-ops/dwell-crm-extension/raw/refs/heads/main/D-WELL-CRM-v0.8.79.zip)，解压到固定目录。
2. 在 Chrome 的 `chrome://extensions` 开启开发者模式，选择「加载已解压的扩展程序」，选取包含 `manifest.json` 的目录。
3. 确认显示版本 `0.8.79`，停用旧版插件，再使用获授权的员工账号登录。
4. 已安装插件不会从 GitHub 自动更新。若是更新原有安装，请替换原加载目录中的文件，在 `chrome://extensions` 点「重新载入」，再刷新 WhatsApp 或 Messenger 页面。

安装包 SHA-256：`35C55C414B26F7EBAE14B3024DEDB292AEC425382B199D84901335E6EC47265E`。

## 相比 GitHub 0.8.71

- WhatsApp 和 Messenger 的「抓近期对话」改为查看当前已加载的最近 10 条消息，包括文字和语音。
- 同一条已选顾客问题可以再次生成 AI 草稿；切换 Agent 后也可重生。新回复失败时保留上一份草稿与推荐照片，重复生成不会重复写入对话进度。
- Messenger 顾客引用我方消息时，不再把引用框中的 emoji／图片错认成发送者头像，减少顾客新回复被当作客服消息、无法在下方选题的问题。无法确认收发方向时仍停止自动抓取；WhatsApp 引用回复已补回归测试。
- 原有 CRM、配套资料、Agent、问答、照片推荐、Flow 与人工发送方式保持不变。插件不会自动发送消息或照片。
- 以上变更通过模拟 WhatsApp／Messenger 对话与本机包测试；客服实际浏览器、真实引用对话及语音仍须在重新载入后核对。

## 0.8.71 旧版试用范围

- 保留 CRM 进单、客户查询、地址复制、优惠券与奖品、好友推荐、幸运抽奖、Flow 和配套资料。
- AI 回复支持选择 Agent、抓取近期已加载的双方文字及语音、生成可编辑草稿、推荐 0–5 张照片，并查看顾客情况与简短对话进度。照片和回复均由客服核对后自行发送，插件不会自动发送。
- 本轮回复优先处理最新、连续的顾客问题；先前已发出的客服消息作为背景，避免重复作答。Messenger 自动 Flow 按钮文字不能当作顾客亲口症状。
- 「保存更好回答」及后台自动提炼优秀回复仍未开发，不包含在此版本。
- 请先用获授权的测试对话试用 AI 回复及语音；真实顾客消息、价格、健康资料和推荐照片都须人工核对。遇到无法识别的消息方向，不要把草稿直接发送。
